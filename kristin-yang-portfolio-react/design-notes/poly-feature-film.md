# Poly App feature showcase

Six background-free, noninteractive feature compositions follow the existing User Log-in showcase. Device frames use the existing thin dark-frame treatment and soft shadows. CSS provides gentle device movement, sequential emphasis for the three meal-recording screens, and scrolling within long screens. Each scene pauses offscreen, with a shared pause button and reduced-motion support.

Sources: user-provided app final mockup.jpg and reward composition screenshot; Figma file HCOeDtH864e30VbxUZ32Er, page 0:1, home frame 170:484. Figma page metadata was available, but the design-context request hit the connector's Starter-plan limit. Screen assets therefore use the original Poly App_medium.pdf exported from the same project, rendered with Poppler at 828px width. No UI was generated or redrawn.
